# EKB SHIELD — Клиентский модпак (.mrpack)

## Что это
Формат `.mrpack` — стандарт Modrinth для лаунчеров (Modrinth App, Prism Launcher,
MultiMC, ATLauncher). Позволяет игроку одним кликом установить клиент со всеми
разрешёнными на сервере модами (Fabric): Sodium, Iris, CPM, Litematica, MaLiLib,
FreeCam, Plasmo Voice, ArmorPoser, ImageFrame Client, Female Gender.

## Состояние индекса
`modrinth.index.json` **заполнен реальными данными** из Modrinth API
(проверено 2026-09-15) под Minecraft **26.1.2** / Fabric Loader **0.19.5**:

| Мод | Версия |
|---|---|
| Sodium | 0.9.2+mc26.1.2 |
| Iris | 1.11.4+26.1 |
| CustomPlayerModels | 26.1v0.6.27b |
| Litematica | 0.27.14 |
| MaLiLib | 0.28.12 |
| FreeCam | 1.4.1+mc26.1.2 |
| Plasmo Voice | fabric-26.1-2.1.17 |
| ArmorPoser | 14.1.0 (beta) |
| ImageFrame Client | 1.2.0 |
| Female Gender | 5.0.0-Beta.5 (beta) |

⚠️ Версия игры называется **26.1.2**, а не «1.26.1.2» — Mojang убрала префикс `1.`
начиная с 26.1 (март 2026).

⚠️ Проект стоит на 26.1.2, а не на более новой 26.2, потому что под 26.2 ещё нет
серверных сборок CoreProtect, BreweryX, EssentialsX и CPM. Подробности — в
`docs/deploy_checklist.md` §1a. Чтобы перейти позже, поменяй `GAME` в `build_index.py`
и пересобери индекс.

## Три мода — вторые половины серверных плагинов (18.09.2026)

ArmorPoser, ImageFrame Client и Female Gender добавлены не «для красоты»:
каждый — клиентская половина уже стоящего на сервере плагина. Без мода плагин
работает вхолостую, сервер шлёт пакеты, а разбирать их на клиенте некому.

| Мод | Серверный плагин | Что даёт |
|---|---|---|
| `armor-poser` | ArmorPoser-Plugin 2.0.1 | позы стоек брони |
| `imageframeclient` | ImageFrame 2026.1.4.0 | картинка в родном разрешении и цвете вместо 128x128 карты |
| `female-gender` | Female-Gender-Mod-Plugin 1.6.0 | правки ванильной модели игрока |

⚠️ ArmorPoser и Female Gender под 26.1.2 существуют только в канале **beta** —
релизов нет вообще. Это не небрежность скрипта, а единственные доступные сборки.

⚠️ Plasmo Voice поднят до **2.1.17** и в модпаке, и на сервере одновременно:
клиент и сервер должны говорить на одном протоколе. Пересобрал индекс —
проверь версию `PlasmoVoice-Paper-*.jar` в `server/plugins/`.

## Обновление индекса
Когда выйдут новые версии модов, пересобрать индекс скриптом:

```bash
py -3 build_index.py ../client_modpack/modrinth.index.json
```

Скрипт берёт для каждого мода последний **release** под указанную в нём
переменную `GAME` + loader `fabric`, подставляет URL, sha1, sha512, размер файла
и текущий стабильный Fabric Loader.

⚠️ Именно release, а не просто самую свежую версию. Modrinth отдаёт версии от
новой к старой, не разделяя каналы, и «самая новая» регулярно оказывается alpha.
На этом уже обожглись: пересборка 18.09.2026 молча подменила FreeCam 1.4.1 на
1.5.0-alpha.1 — и этот alpha уехал бы игрокам как «разрешённый на сервере мод».
Beta берётся только когда релиза под эту версию игры нет вовсе; канал каждой
версии видно в третьей колонке отчёта скрипта. Вручную хэши не считать — они должны совпадать с теми,
что отдаёт CDN Modrinth, иначе лаунчер откажется ставить пак.

## Два модпака: 26.1.2 и 26.2

Сервер работает на 26.1.2, но на нём стоит **ViaVersion 5.11.0**, а он пускает клиентов
более новых версий. Поэтому собраны оба варианта:

| Файл | Версия клиента | Кому |
|---|---|---|
| `ekb_shield_client.mrpack` | 26.1.2 | основной, гарантированно совместим |
| `ekb_shield_client_26.2.mrpack` | 26.2 | кто уже на 26.2 — заходит через ViaVersion |

Пересборка:
```bash
py -3 build_index.py modrinth.index.json 26.1.2 && py -3 pack.py ../ekb_shield_client.mrpack
py -3 build_index.py index_26.2.json      26.2   && py -3 pack.py ../ekb_shield_client_26.2.mrpack index_26.2.json
```

⚠️ Что проверить на 26.2-клиенте перед раздачей игрокам:
- **ресурспак** сервер отдаёт с `pack_format: 84`, клиент 26.2 ждёт 88 — будет
  предупреждение о несовместимости, модели могут не примениться;
- **Plasmo Voice и CPM** общаются с серверными плагинами своим протоколом,
  и ViaVersion их не транслирует — голос и модели могут не заработать.

Если что-то из этого отвалится — играть на 26.2 нельзя, только 26.1.2.

## Сборка .mrpack
```bash
cd client_modpack
py -3 pack.py                     # → ../ekb_shield_client.mrpack
```
Скрипт сам проверяет, что в индексе нет незаполненных хэшей и нулевых размеров,
и не кладёт в архив служебные файлы (README, сами скрипты) — лаунчер копирует
`overrides/` поверх `.minecraft`, лишнее там не нужно.

Без Python: `.mrpack` — обычный zip, в корне которого лежат `modrinth.index.json`
и папка `overrides/`.
Раздать игрокам `ekb_shield_client.mrpack` — они открывают его через
Modrinth App / Prism Launcher, и лаунчер сам скачает все моды и профиль.

## overrides/
Папка `overrides/` копируется поверх `.minecraft` игрока при установке —
сейчас там только базовый `options.txt` (подключение серверного ресурспака, звук).
Дистанция прорисовки намеренно не задаётся — иначе установка пака перезатёрла бы
настройки графики игрока. Можно
добавить сюда `config/` с преднастроенными файлами модов (например
готовый конфиг Sodium под сбалансированную производительность).
