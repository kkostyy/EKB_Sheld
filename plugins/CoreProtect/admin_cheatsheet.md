# EKB SHIELD — Шпаргалка админ-команд CoreProtect

/co i
    Режим инспектора. ЛКМ/ПКМ по блоку показывает историю изменений.

/co rollback u:<Ник> t:<Время> r:<Радиус>
    Откат действий конкретного игрока за указанный период в радиусе.
    Пример: /co rollback u:Igor t:2h r:20

/co rollback t:<Время> r:<Радиус> #see-through
    Откат грифа или взрывов в области без привязки к нику.
    Пример: /co rollback t:30m r:50 #see-through

/co restore
    Отмена последнего проведенного отката (если ошиблись).

/co lookup u:<Ник> t:<Время> a:block
    Просмотр логов без применения отката — только просмотр событий.

Права:
- coreprotect.inspect  — доступ к /co i (можно выдавать разграниченным админам)
- coreprotect.lookup   — доступ к /co lookup
- coreprotect.rollback — доступ к откатам (только у главного админа, см. LuckPerms)
