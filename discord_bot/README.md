# EKB SHIELD — Discord-бот Суда

## Что делает
- `/иск` — подать иск: создаёт номерное дело, публикует embed в `#суд`, открывает тред для доказательств
- `/дела` — список открытых дел
- `/закрыть_дело` — закрыть дело с вердиктом (только роль Администрации/Судьи)

Хранение дел — простой локальный файл `cases.json` (создаётся автоматически), без внешней БД.

## Установка
```bash
npm install
cp .env.example .env
# заполнить .env: DISCORD_TOKEN, CLIENT_ID, GUILD_ID, COURT_CHANNEL_ID, ADMIN_ROLE_ID
npm run deploy   # регистрирует слэш-команды в Discord (один раз / при изменении команд)
npm start        # запускает бота
```

## Как получить нужные ID
- **DISCORD_TOKEN / CLIENT_ID** — из портала разработчиков Discord (discord.com/developers/applications), создать приложение + бота
- **GUILD_ID, COURT_CHANNEL_ID, ADMIN_ROLE_ID** — включить режим разработчика в Discord (Настройки → Расширенные) → ПКМ по серверу/каналу/роли → "Копировать ID"

## Важное ограничение (честно)
Прямой выгрузки логов CoreProtect **из игры в Discord автоматически** этот бот НЕ делает — CoreProtect хранит данные в локальной SQLite базе на сервере Minecraft, а не отдаёт их по сети. Для автоматической выгрузки логов нужен Java-плагин на стороне Minecraft (см. `CourtBridge/`), который по команде админа сам подтягивает данные CoreProtect API и отправляет их в Discord через Webhook.

Сейчас в боте это заменено на ручной процесс: администратор сам выполняет `/co lookup` в игре и вставляет результат в тред дела (текстом/скриншотом).
