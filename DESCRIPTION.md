# EKB SHIELD — полное описание сервера

> Ролевой (RP) сервер Minecraft **26.1.2** на ядре **Purpur**, где всё держится на трёх вещах:
> **настоящей экономике** (алмазы, которые нельзя напечатать), **настоящем Суде**
> (логи CoreProtect вместо «он первый начал») и **расстоянии** (телепортов у игроков нет).

Этот файл — обзор для игроков, будущих администраторов и тех, кто откроет репозиторий
впервые. Техническая кухня (почему сделано именно так и какие грабли пройдены) лежит в
[`CLAUDE.md`](CLAUDE.md), журнал работ — в [`WORKLOG.md`](WORKLOG.md), законы — в
[`docs/`](docs/).

## 1. Коротко о главном

| | |
|---|---|
| **Версия игры** | 26.1.2 (не «1.26»: Mojang убрала префикс `1.` начиная с 26.1) |
| **Ядро** | Purpur, Java 25+ |
| **Клиент** | Fabric + модпак сервера (`ekb_shield_client.mrpack`) |
| **Режим** | Pure Vanilla / RP — без телепортов и привата для игроков |
| **Валюта** | алмаз; 1 блок = 9 алмазов; незеритовый слиток = 128 алмазов |
| **Вход** | только с привязанным Discord-аккаунтом + пароль AuthMe |
| **Главное меню** | `/menu` или клавиша **↓** (стрелка вниз) |

Чем сервер отличается от обычного «выживания с плагинами»:

- **Телепортов нет.** `/home`, `/tpa`, `/spawn`, `/back` игрокам недоступны (Конституция 1.1).
  Расстояние значит всё: для торговли, для войны, для чата и даже для голоса.
- **Привата нет.** Кража — не то, что предотвращают, а то, что **судят**: каждое
  действие пишет CoreProtect, а Суд возвращает вещи по приговору.
- **Деньги не печатаются.** Ни один скрипт не выдаёт алмазы из воздуха. Всё, что
  город платит игрокам, берётся из **Казны** — настоящих сундуков с настоящими алмазами.
  Пустая Казна — скупщик не покупает, казино не принимает ставок.
- **Суд живой.** Заседания по воскресеньям, иски в Discord, логи CoreProtect как
  единственный арбитр, приговоры со ссылкой на статью УК, история рецидивов.

## 2. Как попасть на сервер

1. **Поставь модпак.** Файл `ekb_shield_client.mrpack` открывается в любом лаунчере с
   поддержкой Modrinth (Prism, Modrinth App, ATLauncher). В нём Fabric, оптимизация,
   голосовой чат и клиентские половинки серверных плагинов.
2. **Привяжи Discord.** Сервер пускает только игроков с привязанным аккаунтом
   (DiscordSRV). При первом входе тебя выкинет с кодом — отправь этот код боту
   сервера в личные сообщения и зайди снова. Нужно быть участником Discord-сервера.
3. **Зарегистрируйся в AuthMe.** Сервер работает в offline-режиме, поэтому ник
   защищается паролем: `/register <пароль> <пароль>`, дальше `/login <пароль>`.
4. **Прими ресурспак.** Он обязательный: в нём модели бутылок, конопли, артефактов,
   Тетради Смерти, стволов и настолок. Без него всё это выглядело бы ванильными палками.
5. **Нажми ↓ или набери `/menu`.** Всё остальное — оттуда.

Новичок по умолчанию — **Кочевник**: ничей и свободный. Гражданство, должности и
служба назначаются через Discord и Администрацию.

## 3. Мир и его границы

### Центр мира — Спавн, а не ноль
Точка появления стоит на **−1750 / 75 / 4000**, и граница мира растёт вокруг неё.
Нижний мир центрирован ровно на 1/8 этого: **−218.75 / 500** — иначе игрок, далеко
ушедший по Аду, выходил бы из портала за границей Обычного мира.

### Граница растёт по достижениям
Мир открывается поэтапно — от **4000** до **20000** блоков в поперечнике (Конституция 4.4–4.5):

| Стадия | Что её открывает | Размер |
|---|---|---|
| 1 | старт сервера | 4000 |
| 2 | кто-то впервые вошёл в Нижний мир | ↑ |
| 3 | найдена крепость Ада | ↑ |
| 4 | кто-то вошёл в Край | ↑ |
| 5 | повержен Эндер-дракон | 20000 |

Стадию открывает датапак `ekb_border`: технические достижения повторяют ванильные и
запускают функцию расширения. Новые земли — нейтральные, преимущественного права
на них нет ни у кого. Перед каждой стадией территория прогенерируется заранее (Chunky),
чтобы сервер не генерировал чанки на ходу.

### Ночь
Ночь пропускается, когда спят **25%** игроков в сети. Ванильные 100% на сервере без
телепортов недостижимы: люди разбросаны по своим городам и физически не могут лечь разом.

### Мелочи, которые меняют мир
- **Листва опадает быстро** (Fast Leaf Decay) — срубил ствол, крона осыпалась сама.
- **Мобы с чужими вещами уходят.** В ванили зомби, подобравший меч, становится
  вечным. Здесь он деспавнится, как все, а подобранное падает на землю.
- **Копья без перезарядки** — ванильный откат снят скриптом.
- **Быстрые вагонетки и быстрые счастливые гасты** — транспорт важен, раз телепортов нет.
- **Рецепт бутылочки опыта:** стеклянная бутылка + изумруд. Изумруд — единственный
  «денежный» ванильный предмет, которому проект не дал работы: валюта здесь алмаз.
- **Цветной блеск зачарований** (NotEnoughGlints): предмет + краситель + соты на
  кузнечном столе. Стекло снимает цвет, звезда Незера даёт радужный.
- **Дюп-механики** (нитки, растяжки) оставлены сознательно — это решение хардкорного
  экономического сервера, а не баг.

## 4. Законы: Конституция и Уголовный кодекс

Полные тексты: [`docs/constitution.md`](docs/constitution.md),
[`docs/criminal_code.md`](docs/criminal_code.md), [`docs/rules.md`](docs/rules.md).

### Конституция — главное
- **1.1** Pure Vanilla / RP: у игроков нет привата и телепортов. Персонал телепортируется
  только по службе (доставка в тюрьму, выезд по иску, модерация войн).
- **1.2** Единственный арбитр подлинности — **CoreProtect**.
- **2** Государство = лидер + от 3 граждан + территория + устав в Discord.
- **3** Лидер неактивен 7 дней — референдум; государство неактивно 14 дней — земли нейтральны.
- **3a** Форма правления — восемь строёв, и Суд их учитывает (см. раздел 5).
- **4** Земля: до 8×8 чанков при регистрации, расширение — смежными нейтральными чанками.
- **5** Война объявляется в `#военный-трибунал` за 24 часа, с причиной, целями и условиями
  мира. Нейтралитет и статус беженца защищены.
- **6** Администрация (САП) — надгосударственный арбитр; её база на Спавне нейтральна.

### Уголовный кодекс — по главам
| Глава | Что | Пример наказания |
|---|---|---|
| **1. Собственность** | кража, грабёж, вандализм | возврат вдвойне + штраф 16💎; крупная кража — тюрьма от 10 ч |
| **2. Личность** | **самосуд** (ст. 4), **контракт** (ст. 5), Тетрадь Смерти (ст. 6) | самосуд — 64💎 убитому + тюрьма от 5 ч, повтор — вдвое |
| **3. Экономика** | лавка вне рынка, неуплата аренды, демпинг, скупка краденого | снос, конфискация, штраф 64💎 |
| **4. Процесс** | заседания, иски, исполнение | воскресенье 19:00, Здание Суда |

**Статья 4 — самосуд.** Убивать можно только защищаясь, на объявленной войне или по
контракту. «Он первый начал» доказывается логами, а не словами.

**Статья 5 — контракт.** Контракт не оправдывает убийство, а даёт Суду мотив и цену:
отвечают и исполнитель, и заказчик. Работает это на свидетелях: все, кто был в
48 блоках от убийства, получают уведомление и могут пожаловаться. Молчание свидетеля
ненаказуемо.

## 5. Государства, города и власть

### Города — ClansLite
Клан = город (`/clan`). Создание, приглашения, союзы и враги, очки, PvP внутри города.
`/clan home` **выключен** — это телепорт, а Конституция их запрещает. Чат города — `/cc`.

### Формы правления (`/regime`)
Каждый город объявляет строй, и **Суд это учитывает**:

| Строй | Кто правит | Должности |
|---|---|---|
| Демократия | выборный глава | Глава, Советник, Казначей, Страж |
| Авторитаризм | глава с советом | Глава, Советник, Страж |
| Диктатура | один глава | Глава, Страж |
| Монархия | наследник | Глава, Преемник, Казначей, Страж |
| Олигархия | совет казны | Совет казначеев, Глава-представитель, Страж |
| Теократия | Хранитель | светские должности подчинены ему |
| Коммуна | никто | общая казна, равные доли |
| Анархия | никто | должностей нет |

Глава демократии, правящий мимо голосования, отвечает за узурпацию; в диктатуре тот
же поступок законен — там так объявлено. Строй хранится по названию города: города
живут дольше своих глав.

### Границы государств (`/border`)
Граница **обходится ногами**: глава встаёт в угол своей земли, отмечает точку, идёт по
меже дальше. Получившийся многоугольник Администрация утверждает, и он ложится на
**веб-карту** (squaremap). Лимита площади нет: заявить пол-карты можно, но идти
придётся пол-карты. Граница — **витрина, а не приват**: чужую стройку на твоей меже
разбирает Суд, а не WorldGuard.

## 6. Роли и положение в обществе

### Кочевник и государство
**Кочевник** — состояние по умолчанию: ничей, свободный, его можно нанять. Получив
любую государственную роль, человек перестаёт быть кочевником; потеряв последнюю —
становится им снова, автоматически. Кнопки «сделать кочевником» нет: кочевник — это
отсутствие роли, а не роль.

### Государственные роли (16)
Судья · Врач Клиники · Гражданин · Житель Спавна · Глава города · Советник · Казначей ·
Страж · Шериф Спавна · Бригадир строителей · Почтальон · Приказчик Мэрии · Бармен ·
Крупье · Следователь · Журналист.

### Роли вне государства
**Стример** и **Ютубер** (право бесплатного анонса эфира `/onair`), **Теневое
Сообщество** (подполье, см. раздел 10). Помощник администратора — Администрация, а не
государство.

### Роль видно сразу
Над головой, в списке игроков и в чате стоит цветной тег старшей роли:

`[Админ]` · `[Помощник]` · `[Судья]` · `[Шериф]` · `[Следователь]` · `[Врач]` ·
`[Глава]` · `[Советник]` · `[Казначей]` · `[Страж]` · `[Пресса]` · `[Стример]` ·
`[Ютубер]` · `[Бригадир]` · `[Почтальон]` · `[Приказчик]` · `[Бармен]` · `[Крупье]` ·
`[Гражданин]` · `[Спавн]` · `[Кочевник]`

Тег ставится сам — при входе, при выдаче роли и раз в пять минут. **Теневое Сообщество
тегом не показывается никогда**, а надетая Личина прячет тег в списке игроков.

### Раздача ролей — головами
Администрация открывает `/ekbroles`, кликает по голове игрока и щёлкает по ролям. Никаких
ручных `/lp user … permission set …` с риском опечатки. Группу главного администратора
это меню не выдаёт в принципе.

## 7. Экономика: алмазы, Казна и торговля

### Валюта
**Алмаз.** Блок алмазов = 9, незеритовый слиток = 128, незеритовый блок = 1152.
Цены на всё — в [`docs/price_list.md`](docs/price_list.md). Долларов EssentialsX на сервере
по сути нет: Vault их видит, но ни одна механика проекта ими не платит.

### Казна Спавна
**Физические сундуки** с настоящими алмазами (`/treasury` — баланс). Через Казну ходят
**все** деньги города: скупщик, аренда палаток, марки почты, ставки казино, лотерея,
стойка бара, газета, экспертиза. Казна конечна — это рычаг Мэрии, а не баг. Её можно
ограбить, и это дело Суда. Сундуков может быть сколько угодно, первый — кассовый.

### Торговая Коллегия (`/market`)
- **Скупщик** (`/skupka`) — окно с 35 позициями по прайсу: игрок отмечает, что готов
  отдать, и получает алмазы из Казны. Крупные партии (булыжник 256 → 1💎, железо 16 → 1💎).
  Сырьё уходит на отдельный склад стройматериалов, а не в Казну.
- **Аренда торговой палатки** на Рыночной площади.
- **Доска лотов** (`/lot`, `/lots`) — бартер и личные сделки.

### Лавки игроков — Shopkeepers
Лавка торгует **из сундука владельца** (до 3 лавок, сундук не дальше 15 блоков).
Валюта — алмаз, крупная — алмазный блок по курсу 9. Яйцо торговца продаётся за 16💎
(`/shopegg`) — в Казну.

### Аукцион (`/auction`, `/ah`)
Настоящий аукцион с эскроу: вещь снимается с продавца при выставлении, ставка — с
покупателя сразу, перебитому возвращается. Шаг +5%, торги 30 минут, ставка в последнюю
минуту продлевает их ещё на минуту (антиснайп). Кто не в сети при закрытии — получит
при входе.

### Наём кочевников (`/hire`)
Работа вместо войны: наниматель выбирает кочевника головой, срок (30/120/240
онлайн-минут), цену называет сам кочевник. Пока идёт наём, **кочевника нельзя бить — и
он не бьёт** (только между игроками: мобы, лава и падение бьют как обычно). Кочевник,
на которого открыт контракт, наняться не может.

## 8. Азарт: казино, кости, лотерея

Всё азартное идёт **через Казну**: ставка ложится в сундук города, выигрыш достаётся
оттуда же. Броски честные (`random`), перевес заведения — в выплатах, и он написан на
кнопках. Перед каждой ставкой проверяется, потянет ли Казна **максимальный** выигрыш.

| Игра | Команда | Выплата | Ожидание игрока |
|---|---|---|---|
| Кости | `/dice` | 5💎 при 5–6 за ставку 2💎 | 0.83 |
| Рулетка | `/roulette` | красное/чёрное ×2, зеро ×24 | 0.97 / 0.65 |
| Автоматы | `/slots` | три одинаковых ×18, два — возврат | 0.92 |
| Монета | `/coinflip` | ×2 при шансе 45% | 0.90 |

### Лотерея Спавна (`/lottery`)
- Билет — **1💎**, не больше **16** на человека за тираж.
- Тираж — **раз в сутки**, победитель один, шанс пропорционален билетам.
- Победитель забирает **80%** банка, остальное остаётся Казне.
- Участников меньше двух — тираж переносится вместе с банком и билетами.
- Если Казна была пуста в день тиража, выигрыш **не сгорает**: он лежит долгом и
  выдаётся при входе или по `/lottery claim`.

Купить: `/lottery buy [N]` или правой кнопкой по «Лотерее» в меню «Бар и кости».

## 9. Суд, тюрьма и следствие

### Суд
- Иски — в Discord `#суд` (бот: `/иск`, `/дела`, `/закрыть_дело`).
- Заседания — по воскресеньям в 19:00 в Здании Суда Спавна.
- Доказательства — логи **CoreProtect**. Администратор выгружает их прямо в канал дела
  плагином **CourtBridge** (`/courtlog <игрок> <минуты> <радиус> <номер_дела>`).
- Жалоба из игры — `/report <ник>` (причину спросит окно).

### Приговор
`/sentence <ник> <минут> [статья]` — окно спрашивает **статью УК перед сроком**:
приговор без статьи — не приговор. История приговоров (`/jailhistory`) нужна для
рецидива: УК прямо говорит «при повторном — срок удваивается».

### Тюрьма
- Срок тикает **только онлайн** — отсидеть его, выйдя из игры, нельзя.
- При посадке весь инвентарь уходит в **судейский ящик**; в камере нельзя ломать и
  строить, но передачки (еду, напитки, самокрутки) употреблять можно.
- Побег эндер-жемчугом и хорусом пресекается.
- По окончании срока вещи **не возвращаются сами**: судья разбирает ящик поштучно
  (`/jailprop`) — что вернуть владельцу, что конфисковать в Казну.
- Куда выйти, выбирает освобождённый: кровать, спавн мира или крыльцо Суда.

### Следствие
- **Свидетели.** При каждом убийстве все в 48 блоках получают уведомление. Список
  свидетелей снимается в момент убийства; показания даются головами (`/witness`).
  В окне есть кнопка «Промолчать» — молчание законно.
- **Криминалистика** (`/expertise`) — осмотр места убийства за последние 72 часа: успех
  50%, одна попытка на место, за пустое поле денег не берут.
- **Досье** на игрока — тюрьма, приговоры, зависимость, должности, наём одним окном.
- **Смерть объявляется, но не рассказывает, от чьей руки** — узнавать это работа следствия.

## 10. Тёмная сторона: контракты, Личина, Теневой Рынок

### Контракты на устранение (`/contract`)
- Заказчик вносит депозит **алмазами из рюкзака** — они реально списываются и лежат в
  эскроу.
- Исполнитель берёт контракт, а после гибели цели получает **голову жертвы** с номером
  контракта. Деньги он получает, только принеся голову заказчику лично — у заказа есть
  физический след.
- **Анонимны все трое:** заказчик не показан никому, исполнитель ходит под постоянным
  псевдонимом («Ворон-42»), **жертва не знает, что заказ есть**.
- Репутация копится у псевдонима: «Ворон-42 · 5 из 7», рейтинг подполья — `/contract rep`.
- Настоящие ники пишутся в журнал Администрации — Суд их поднимет, игроки — нет.

### Личина (`/disguise`)
Чужой скин и псевдоним в списке игроков. Ник над головой не прячется — Суду нужна хоть
одна ниточка: кто стоит рядом, тебя узнает.

### Теневой Рынок (`/blackmarket`)
Место сбора подполья. Координаты видят только члены Теневого Сообщества.

## 11. Особые предметы

### Тетрадь Смерти
Одна-две на весь сервер. Имя вписывается в книгу, книга подписывается — и человек
умирает. Кулдаун, лимит тетрадей, розыск потерянной (раз в минуту трекер ищет её у
игроков, в брошенных предметах и схронах). **Действует везде, включая Главный город** —
это единственный по-настоящему глобальный артефакт.

### Шесть артефактов — по два на мир
Компас Охотника · Кинжал Теневого Шага · Песочные часы · Чёрная Метка · Маска ·
Печать Изгоя. У каждого экземпляра номер, владелец, кулдаун и заряды; кулдаун не
обнуляется передачей из рук в руки.

### Бур 3×3
Книга кладётся на кирку **на наковальне** — кирка начинает копать 3×3 по взгляду.
Фортуна и шёлк работают, защита WorldGuard соблюдается, сундуки и бедрок не трогаются.

### Стволы и настолки
Оружие QualityArmory (выдаёт только главный админ, крафта и магазина нет) и
настольные игры TablePlays (шахматы, карты, кости, фишки).

### Каталог (`/allitems`)
Разделы: Конопля (16), Напитки (14), Артефакты (6), Тетрадь, Стволы, Настолки. В
творческом инвентаре этого нет и быть не может — клиент собирает его сам. Конопля
видна во вкладке креатива благодаря собственному моду сервера.

## 12. Вещества: алкоголь, трава и зависимость

### Алкоголь — BreweryX
14 напитков: пиво, ликёры, водки, виски, ром, самогон, текила и **Рассол** —
отрезвитель. У каждой бутылки свой 3D-силуэт и пиксельная эмблема на этикетке.
Купить можно у живых барменов или на стойке города по полной цене прайса
(стойка держит потолок цены — зарабатывать должны живые бармены).

### Конопля — порт мода Nirvana
Семена → грядка → сушка на костре → трепание волокна на ткацком станке →
самокрутка, трубка, бонг, брауни, мазь, шляпа. Эффект «Умиротворение» стакается;
у обкуренных криперы тоже обкуренные.

### Зависимость
Две раздельные шкалы — алкогольная и травяная. С 10 доз ты зависим, и без дозы
онлайн-время работает против тебя: 20 минут — тошнота и голод, 45 — плюс слабость и
замедление. **Шкала не спадает от воздержания** — перетерпеть нельзя. Рассол и молоко
глушат симптомы на 5 минут, вылечить может только врач (`/addiction cure`) или смерть.

## 13. Связь: чат, голос, рации, почта, газета

### Чат — CarbonChat
- **Локальный** (по умолчанию) — 150 блоков. Расстояние значит что-то.
- **Глобальный** — `/g` или префикс `!`.
- **Город** — `/cc`. **Служебный** — для персонала.
- Перед ником — цветной тег роли.

### Голос — Plasmo Voice + Simple Voice Chat
- Голос слышно по расстоянию (8/16/32 блока), шёпот — вплотную.
- **Группы** (`/groups`) — своя частота отряда на любом расстоянии.
- Скалк-датчики и вардены **слышат голос** — в Глубоком Тёмном молчи.
- Музыкальные пластинки с записанным звуком, голосовые сообщения.
- **Мост VoiceConnector2:** игроки с Plasmo Voice и с Simple Voice Chat слышат друг друга.
- **Зоны тишины:** в отмеченных регионах голосом не говорят (слушать можно). Участники
  региона — например, судья в зале — говорить могут.

### Рация — Simple Voice Radio
Блок-рация: частота 1–15, режимы приёма и передачи. Крафт: 3 меди / железо,
проигрыватель, железо / редстоун, незеритовый слиток, редстоун. Дальность дают
**громоотводы-антенны** над рацией, а молния в антенну сжигает рацию навсегда.

### Ламповая Почта (`/pochta`)
Письмо — 1💎, посылка вещью — 4💎. Доставка с задержкой, по часам сервера, а не
отложенной задачей: перезапуск сервера посылку не теряет.

### Газета «EKB SHIELD Times» (`/press`)
Журналист пишет выпуск в книге и подписывает её, копии продаются игрокам. Экстренная
новость — `/newsflash`, анонс эфира стримера — `/onair`.

### Прочее
Сесть и лечь (`/gsit`, `/glay`), нести игрока на руках, погладить друга (Headpat),
позы стоек брони, картинки на картах (ImageFrame), экраны (DreamDisplays).

## 14. Главный город (Спавн)

Регион `spawn` — 384×384 вокруг точки появления. Правила города:

- **Стройка** — только Администрация и те, кого Мэрия наняла рабочими (`/spawnbuild`,
  выдача головами, бессрочно).
- **PvP запрещён — кроме случая, когда на жертву есть активный заказ.** Правило
  проверяется у обоих участников: из города нельзя расстреливать тех, кто снаружи.
  Отказ сформулирован нейтрально: неудачная попытка неотличима от «здесь не дерутся».
- **Тетрадь Смерти действует и здесь** — безопасная зона от неё не спасает.
- **Сундуки не заперты** — кража судится, а не предотвращается.

В городе: Мэрия и Казна, Торговая Коллегия и Рыночная площадь, Бар и казино, Почта,
Здание Суда, тюрьма, Клиника, редакция газеты.

**Вызов служб** (`/calls`): медик, суд, шериф, строительная бригада, почта.

## 15. Меню и управление

**Открыть:** клавиша **↓** (стрелка вниз, мод Keybind) или `/menu`.
Клавишу можно переназначить: *Настройки → Управление → Keybind*.

### Структура
```
EKB SHIELD (/menu)
├─ Профиль     — голос, скины, контракты, Личина, почта, Discord, клавиши, роли
├─ Торговля    — Коллегия, почта, бар и казино, Теневой Рынок (подполье)
├─ Мир         — город, газета, Кровавый Сон
├─ Законы      — Конституция, УК, шериф, криминалистика
└─ Служба      — меню каждой роли и Администрация
```

69 меню, более 900 кнопок. Все меню собираются генератором из одной спецификации
([`menus_spec.py`](menus_spec.py)); полная карта — [`docs/menu_map.md`](docs/menu_map.md).

### Как устроены кнопки
- **Кнопка либо что-то делает, либо её нет.** Справка ужата до двух строк, длинные
  тексты уходят в чат по клику.
- **Аргументы собирает мастер**, а не игрок в чате: цель выбирается **головой** из
  онлайна, время и радиус — кнопками, свободный текст — одной строкой. Перед
  выполнением показывается собранная команда целиком, выполняется она **от твоего
  имени** — мастер прав не добавляет.
- Разделы видны по правам: судья видит меню судьи, врач — врача.
- «Назад» ведёт туда, откуда в раздел действительно попадают.

## 17. Администрация и надзор

### Иерархия
- **Главный администратор** (`admin`) — всё.
- **Помощник администратора** (`restricted_admin`) — по принципу **«смотреть можно,
  менять нельзя»**: инспектор CoreProtect есть, откатов нет; чужой инвентарь открыть
  можно, изъять — только по решению Суда; ваниш есть, видеть главного админа — нет.
  Тетрадь Смерти, артефакты, стволы и дрон — только у главного.

### Надзор
- **MinerTrack** — анти-X-Ray по поведению шахтёра. **Никого не кикает сам**:
  подозрение — повод для проверки по логам, а не приговор.
- **BetterReplay** — запись игроков на сервере без модов, для разбора спорных дел.
- **CoreProtect** — вся история блоков, сундуков, убийств.
- **Журнал действий Администрации** (`/adminlog`) — кто ушёл в спектатор, кто открывал
  чужой рюкзак, кто выдал право стройки. Помощник видит только свои записи.
- **Наблюдение за игроком** — клик по голове: ваниш → спектатор → прыжок. Обратно —
  `/specback`.
- **ClientID** и **CloudAC** — фильтр читерских клиентов.

### Раздел «Надзор и техника» (`/admintech`)
История X-Ray, записи повторов, пересчёт тегов ролей, тираж лотереи вне расписания,
выдача рации, редактор горячих клавиш, дрон-камикадзе с глушилкой и детектором РЭБ
(забава главного админа).

## 23. Принципы проекта

1. **Деньги не печатаются.** Любая выплата игроку идёт из конечной Казны.
2. **Кражу судят, а не предотвращают.** Привата нет, логи есть.
3. **Расстояние что-то значит.** Нет телепортов, локальный чат, голос по дальности,
   рации с антеннами.
4. **Кнопка либо что-то делает, либо её нет.**
5. **Смотреть можно, менять нельзя** — для всех, кроме главного администратора.
6. **Адресное — лично, объявления — публично.** Приговоры, тиражи и границы —
   на площадь; наём, заявки и подозрения — только сторонам.
7. **Свой скрипт лучше чужого плагина, который ломает экономику.** Плагины на
   Vault-долларах заменены своими механиками на алмазах.
8. **Подполье анонимно, но не безответственно.** Псевдонимы для игроков, настоящие
   имена — для Суда.
