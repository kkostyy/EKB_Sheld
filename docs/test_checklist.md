# Чек-лист проверки EKB SHIELD

Составлен 28.09.2026 после запуска сервера. Сверен с кодом: пункты описывают,
как механика устроена на самом деле, а не как её себе представляли.
Нужны два человека: **А** — админ, **Т** — тестер без прав.

## 0. Сделать руками до проверки

- [ ] Discord → Роли: «🤖 『 ⚙️ 』 Bots» перетащить сразу под «👑 Admin Staff».
      Пока роль внизу, боты не выдают роли (`50013 Missing Permissions`).
- [ ] Регион здания казино: в углах `//pos1`, `//pos2`, затем `/rg define casino`.
      Пока его нет, казино закрыто для всех.
- [ ] Казна назначена (`/settreasury`, `/addtreasury`), в ней есть алмазы.
- [ ] Т привязал Discord (`/discord link`) — без привязки не пустит.

## 1. Discord

- [ ] Новый участник сразу получает роль **Nomad**.
- [ ] Т с ролью **Prisoner / Muted** не пишет в чаты и не заходит в голосовые.
- [ ] Т не видит категорию 🕋管理室 (логи, консоль, аудиты).
- [ ] В `🎰・аудит-казино` есть проверочное сообщение от SRVLOG.

## 2. Роли Discord ⇄ Minecraft

- [ ] Выдать Т в Discord **Moderator** → в игре у него группа `restricted_admin`
      (`/lp user Т info`). Снять → группа ушла.
- [ ] Выдать в игре через `/ekbroles` **Судью** → в Discord появилась
      Tribunal Judge. Снять → ушла.
- [ ] Выдать госроль (Гражданин) → в течение минуты снят Кочевник, и в игре,
      и в Discord (Nomad). Снять последнюю госроль → Кочевник вернулся.
- [ ] Стример / Ютубер не снимают Кочевника (не госроли).
- [ ] Теневое Сообщество в Discord не появляется ни у кого.
- [ ] Admin Staff из Discord НЕ даёт группу `admin` в игре.
- [ ] Тег роли в чате и в TAB сменился в течение минуты.
- ⚠ Роли выдавать при работающем сервере: выданное в Discord при выключенном
  сервере при входе игрока снимется.

## 3. Контракты и Личина

- [ ] А заказывает Т (`/contract new`): депозит списан, Т не получает ничего.
- [ ] Т: `/contract board` — своего заказа не видит; `/contract take <id>` на
      свой номер отвечает «Такого контракта нет».
- [ ] Исполнитель берёт контракт — заказчик видит только псевдоним.
- [ ] Исполнитель убивает Т → получает ГОЛОВУ, денег ещё нет. Свидетели в 48
      блоках получают сообщение и `/witness`.
- [ ] Личная передача: ПКМ головой по заказчику без Личины → Личина
      надевается сама (скин сменился), второй ПКМ → алмазы исполнителю.
- [ ] Почтой: `/contract mail` с головой в руке → марка 4💎 в Казну, через
      20 минут голова у заказчика с подписью-псевдонимом, награда исполнителю.
      Исполнитель не в сети → награда при входе.
- [ ] `/mailbox` исполнителя: «для заказчика по контракту №N», без ника.
- [ ] Обычный `/parcel` голову не принимает. Голову нельзя поставить блоком.
- [ ] Чужая (украденная) голова выплату не открывает.

## 4. Свидетели и экспертиза

- [ ] `/expertise` на месте убийства (≤72 ч): шанс 50%, место осматривается
      один раз. На пустом месте денег не берут.
- [ ] `/witness` открывается только у того, кто был рядом; кнопка «Промолчать».

## 5. Тюрьма

- [ ] Посадить Т на 15 мин со статьёй: инвентарь ушёл в судейский ящик,
      ломать и ставить в камере нельзя, еду и напитки можно.
- [ ] Стоять неподвижно минуту → засчитывается полминуты (AFK вдвое дольше).
- [ ] ⚠ Встать в поток воды → срок идёт полностью (известная дыра, проверить).
- [ ] Выйти и зайти → срок стоял, пока Т не было.
- [ ] Эндер-жемчуг и хорус в камере не работают.
- [ ] После срока вещи сами не вернулись: `/jailprop` или `/jailitems give`.
- [ ] `/jailhistory Т` — статья записана.

## 6. Бур, граница, Кровавый Сон

- [ ] Кирка + книга (CMD 7801) на наковальне → кирка с буром; копает 3×3,
      не трогает сундуки и чужой регион, фортуна работает.
- [ ] За границей мира — урон. Граница Ада = 1/8, центр −218.75 / 500.
- [ ] `.\purge.ps1 -WhatIfOnly` показывает план, ничего не трогая.

## 7. Главный город

- [ ] Т не может ударить игрока в регионе `spawn`; по цели с контрактом — может.
- [ ] Стрельба изнутри наружу тоже запрещена.
- [ ] Т не может ломать блоки на Спавне; `/spawnbuild` → может.

## 8. Казино

- [ ] Вне региона `casino`: `/roulette`, `/slots`, `/coinflip`, `/dice`,
      `/casinohall`, `/chips buy` — «Играют только в здании казино».
- [ ] Набрать вручную `/casinoroulette:casino` → отказ.
- [ ] В здании: `/chips buy 4` → 4 жетона (фишка с алмазом), в Казне +4💎.
- [ ] `/casinohall` → меню плагина; рулетка, слоты, краш на жетоны.
      Колеса фортуны и ежедневного колеса нет.
- [ ] Жетон нельзя поставить блоком.
- [ ] `/chips sell all` → алмазы из Казны. С пустой Казной жетоны остаются.
- [ ] `/casinoclose тест` → окна у игроков закрылись, ставки не принимаются,
      `/chips sell` работает. `/casinoopen` → открыто.
- [ ] В `🎰・аудит-казино` пришли: ставки, касса, закрытие и открытие.
- [ ] Обмен «своя сумма» (ввод в чат) в меню плагина: число НЕ должно уйти
      в общий чат.
