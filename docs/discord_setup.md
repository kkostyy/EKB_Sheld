# 💬 Настройка Discord для EKB SHIELD

Что нужно создать: **два бота** (у каждого свой токен), **один вебхук** и **структуру каналов**.
Один токен на двух ботов не годится — процессы будут выбивать друг друга из соединения.

---

## 1. Структура каналов

### Обязательные — на них завязаны конфиги

| Канал | Тип | Кто видит | Куда прописывается |
|---|---|---|---|
| `общий-чат` | текстовый | все | `Channels.global` в DiscordSRV — мост с чатом Minecraft |
| `суд` | текстовый | все | `Channels.суд`, `COURT_CHANNEL_ID` бота, вебхук CourtBridge |
| `военный-трибунал` | текстовый | все | `Channels.военный-трибунал` — объявления войн (Конституция 5.1) |
| `admin-logs` | текстовый | **только админы** | `Channels.admin-logs` — алерты: алмазы, незерит, спавнеры, шалкеры, маяки |
| `консоль` | текстовый | **только главный админ** | `DiscordConsoleChannelId` — полная консоль сервера |

⚠️ `консоль` — это не просто логи: из него можно **выполнять команды сервера**. Доступ только
главному админу, иначе любой, кто туда попадёт, получит права оператора.

### Рекомендуемые — под документы проекта

| Канал | Что туда |
|---|---|
| `правила` | `docs/rules.md` |
| `конституция` | `docs/constitution.md` |
| `уголовный-кодекс` | `docs/criminal_code.md` |
| `прайс-лист` | `docs/price_list.md` |
| `регистрация-государств` | Уставы государств (Конституция 2.3: лидер, 3 гражданина, территория) |
| `объявления` | расширения границ мира, ивенты, Судная Ночь |
| `заявки` | тикеты на разбан и пересмотр решений (Правила 1.11) |

Все документные каналы — только для чтения: право «Отправлять сообщения» снять у @everyone.

### Роли

| Роль | Кому | Где используется |
|---|---|---|
| `Администрация` | главный админ, судьи | `ADMIN_ROLE_ID` бота суда (право закрывать дела), пинг в алертах |
| `Оператор` | разграниченные админы | соответствует группе `restricted_admin` в LuckPerms |
| `Гражданин` | игроки | выдаётся после привязки аккаунта |

## 2. Бот №1 — DiscordSRV (мост чата и алерты)

1. https://discord.com/developers/applications → **New Application** → имя, например `EKB SHIELD Bridge`.
2. Вкладка **Bot** → **Reset Token** → скопировать. Показывается ОДИН раз.
3. Там же, раздел **Privileged Gateway Intents**, включить оба — без них плагин не подключится:
   - `MESSAGE CONTENT INTENT`
   - `SERVER MEMBERS INTENT`
4. **OAuth2 → URL Generator**:
   - Scopes: `bot`
   - Bot Permissions: `View Channels`, `Send Messages`, `Embed Links`, `Read Message History`,
     `Manage Webhooks`, `Attach Files`
   - Открыть полученную ссылку и пригласить бота на свой сервер.
5. Вписать токен и ID каналов в `D:\EKB_Shield\server\plugins\DiscordSRV\config.yml`:
   ```yaml
   BotToken: "токен_бота_1"
   Channels: {"global": "ID", "admin-logs": "ID", "суд": "ID", "военный-трибунал": "ID"}
   DiscordConsoleChannelId: "ID_канала_консоль"
   ```
6. В `plugins/DiscordSRV/alerts.yml` заменить `ROLE_ID_ГЛАВНЫЙ_АДМИН`, если нужен пинг по спавнерам.

## 3. Бот №2 — суд (`/иск`, `/дела`, `/закрыть_дело`)

1. Там же **New Application** → `EKB SHIELD Court`.
2. **Bot → Reset Token** → скопировать.
3. **OAuth2 → URL Generator**: scopes `bot` **и** `applications.commands` (без второго слэш-команды
   не зарегистрируются), права: `View Channels`, `Send Messages`, `Embed Links`,
   `Create Public Threads`, `Send Messages in Threads`.
4. Со вкладки **General Information** скопировать **APPLICATION ID** — это `CLIENT_ID`.
5. Заполнить `discord_bot\.env`:
   ```
   DISCORD_TOKEN=токен_бота_2
   CLIENT_ID=application_id
   GUILD_ID=id_сервера
   COURT_CHANNEL_ID=id_канала_суд
   ADMIN_ROLE_ID=id_роли_Администрация
   ```
6. Запустить:
   ```bash
   cd discord_bot
   npm install
   npm run deploy   # регистрация слэш-команд, один раз
   npm start
   ```

## 4. Вебхук для CourtBridge

Логи CoreProtect в `#суд` шлёт не бот, а вебхук:

Настройки канала `суд` → **Интеграции** → **Вебхуки** → **Создать вебхук** → **Копировать URL**
→ вписать в `D:\EKB_Shield\server\plugins\CourtBridge\config.yml`:
```yaml
discord-webhook-url: "https://discord.com/api/webhooks/..."
```

## 5. Как узнать ID

Discord → Настройки → **Расширенные** → включить **Режим разработчика**.
Дальше ПКМ по серверу / каналу / роли → **Копировать ID**.

## 6. Проверка

После заполнения перезапустить сервер и убедиться, что в логе НЕТ строки
`An invalid length bot token` и есть подключение DiscordSRV. Затем:
- написать в `общий-чат` — сообщение должно появиться в игре, и наоборот;
- сломать алмазную руду — в `admin-logs` должен прийти embed;
- `/courtlog <ник> 60 30 1` в игре — выгрузка логов должна прийти в `суд`.
