# Кастомные скины

Сюда кладутся PNG-файлы скинов. Имя файла = имя скина в игре
(`ivan.png` → `/skin ivan`).

```bash
py -3 add_skins.py            # показать, что будет загружено
py -3 add_skins.py --write    # загрузить и зарегистрировать на сервере
```

## Требования к файлу

- PNG, 64×64 (новый формат) или 64×32 (старый).
- Имя: латиница, кириллица, цифры, `_` и `-`. Пробелы скрипт сам
  заменит на `_`: имя набирают в команде `/skin <имя>` одним словом.
- Карта «старый файл → новое имя» после переименования 25.09.2026 —
  `renamed.json`.
- Тонкие руки (Alex) — суффикс `_slim`: `ivan_slim.png` даст скин `ivan`
  с моделью slim.

## Почему нельзя просто положить PNG в плагин

SkinsRestorer хранит скины не картинками, а парой `value` + `signature`
(`plugins/SkinsRestorer/skins/*.customskin`). Подпись ставит Mojang, и
подделать её локально нельзя — клиент такой скин не примет.

Поэтому `add_skins.py` идёт кружным путём: заливает PNG на MineSkin (там
его подписывают), получает URL готовой текстуры и отдаёт серверу команду
`sr createcustom <имя> <url>`. Это ровно то, что SkinsRestorer делает сам
для `/skin url`, — своего пути в обход подписи у него нет.

## Что нужно, чтобы сработало

- Сервер запущен (регистрация идёт по RCON, `rcon.py`).
- Есть интернет: PNG уходит на `api.mineskin.org`.
- Ключ MineSkin необязателен, но без него очередь медленнее.
  Свой ключ — в `plugins/SkinsRestorer/config.yml`, `mineskinAPIKey`.

## Учёт

Загруженное записывается в `skins/uploaded.json`, чтобы повторный запуск
не гонял на MineSkin то же самое. Поменял картинку — удали её строку
оттуда либо запусти с `--force`.

## Выдача

- Игроку: `/skin <имя>`.
- Список: `/skins` (GUI), кастомные скины там включены
  (`gui.custom.enabled: true`).
- Снять: `/skin clear`.
